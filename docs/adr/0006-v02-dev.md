# ADR 0006 — v0.2, campagne et Couronne de développement

Contexte : une v0.2 jouable jusqu'à M7 est demandée, sans identifiants Play Console, clé de production ni appareils physiques connectés.

Décision : créer une cérémonie DEV hors ligne avec une racine privée dans `.dev-crown/` (ignorée par Git, jamais compilée). Les clients DEV embarquent une Genèse et une clé opérationnelle de Trône de test certifiée 30 jours. Le Trône DEV est activable après authentification Android. Cette autorité partagée est volontairement réservée aux essais ; elle ne représente aucune sécurité d'administration en production.

La boutique DEV délivre des reçus de test signés sans transaction bancaire. Google Play Billing 8 est intégré, mais le parcours financier est désactivé pour la DEV. Les Maisons peuvent être fondées avec deux compagnons explicitement identifiés comme personnages de test. Le protocole de Maison distingue cette exception des trois serments et témoignages BLE nécessaires en conditions réelles.

Les paquets v0.2 utilisent des sessions Ed25519 certifiées par une clé P-256 et un espace réseau v02 séparé de v0.1. Les sauvegardes v0.1 sont migrées sans changer le Nom. Les anciens replays dépendent de l'ancienne simulation et ne sont pas compatibles bit à bit avec les règles v0.2.

Alternatives rejetées : prétendre attester un émulateur ; encaisser des paiements sans configuration éditeur ; inclure une racine de production sur un téléphone ; déclarer réussis des essais sur deux opérateurs mobiles absents.
